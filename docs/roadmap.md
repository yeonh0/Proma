# 개발 로드맵

## 개요

기능 → 안정성 → 사용성 → 디자인 순 우선순위로 Phase를 진행한다.
각 Phase는 독립적으로 빌드/동작 가능한 상태를 유지해야 한다.

## Phase 진행 원칙

- 각 Phase는 이전 Phase가 **완료 조건을 모두 만족**한 후 시작
- Phase 내 Task는 순서대로 진행하며 각 Task 완료 시 즉시 Commit
- Phase 완료 시 해당 Task 문서를 `docs/tasks/completed/` 로 이동
- 중간에 버그 발견 시 현재 Task를 중단하고 `fix()` Task를 먼저 처리
