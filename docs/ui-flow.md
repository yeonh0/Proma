# UI 화면 구조 및 흐름

## 레이아웃 원칙

- **기본 레이아웃**: 사이드바(좌) + 메인 콘텐츠(우) 2단 구성
- 초기 목표는 기능 완성 — 과도한 디자인 금지
- 사이드바는 항상 고정, 메인 영역만 라우팅으로 전환

---

## 전체 화면 구조

```
┌────────────┬────────────────────────────────────────┐
│            │  헤더 (페이지 제목 + 주요 액션 버튼)      │
│  사이드바   ├────────────────────────────────────────┤
│            │                                        │
│ ▸ 대시보드  │                                        │
│ ▸ 프로젝트  │         메인 콘텐츠 영역                  │
│ ▸ 일정     │                                        │
│ ▸ 메일     │                                        │
│ ▸ 설정     │                                        │
│            │                                        │
└────────────┴────────────────────────────────────────┘
```

---

## 화면별 상세 설계

### 1. 대시보드 (`/`)

**목적**: 전체 현황을 한눈에 파악

**표시 항목**:
- 진행 중 프로젝트 수 / 완료 프로젝트 수
- 오늘 일정 목록 (최대 5개)
- 마감 임박 Task 목록 (7일 이내)
- 최근 가져온 이메일 (최대 5개)
- 미확인 AI 분석 결과 수

**레이아웃**:
```
┌──────────────┬──────────────┬──────────────┐
│ 프로젝트 현황  │   오늘 일정   │  마감 임박   │
└──────────────┴──────────────┴──────────────┘
┌──────────────────────────┬─────────────────┐
│      최근 이메일           │  미확인 AI 결과  │
└──────────────────────────┴─────────────────┘
```

---

### 2. 프로젝트 목록 (`/projects`)

**목적**: 프로젝트 전체 목록 관리

**기능**:
- 프로젝트 목록 (카드 또는 테이블 뷰)
- 상태 필터 (전체 / 진행 중 / 완료 / 보관)
- 우선순위 필터
- 새 프로젝트 생성 버튼

**화면 흐름**:
```
프로젝트 목록
    │
    ├─ [새 프로젝트] → 모달: 제목 / 설명 / 우선순위 / 시작일 / 마감일
    │
    └─ [프로젝트 카드 클릭] → 프로젝트 상세 (/projects/:id)
```

---

### 3. 프로젝트 상세 (`/projects/:id`)

**목적**: 단일 프로젝트의 상세 정보 및 하위 Task 관리

**탭 구성**:
```
[ 개요 ] [ Task 목록 ] [ 연관 일정 ] [ 연관 메일 ] [ AI 분석 ]
```

**개요 탭**:
- 제목, 설명, 상태, 우선순위, 날짜 (편집 가능)
- 프로젝트 삭제 버튼 (확인 다이얼로그 필수)

**Task 목록 탭**:
- todo / in_progress / done 컬럼 (칸반 또는 리스트)
- Task 추가 / 수정 / 삭제
- 상태 변경 (드래그 or 드롭다운)

**연관 메일 탭**:
- 해당 프로젝트에 연결된 이메일 목록
- 메일 연결 / 연결 해제 기능

**AI 분석 탭**:
- 프로젝트 요약 요청 버튼
- AI 결과 목록 (미적용 / 적용됨 구분)
- [적용] 버튼 → 사용자 확인 후 적용

---

### 4. 일정 (`/schedule`)

**목적**: 날짜 기반 일정 관리

**뷰 구성**:
- 월별 캘린더 뷰 (기본)
- 목록 뷰 (토글 전환)

**기능**:
- 날짜 클릭 → 일정 추가 모달
- 일정 클릭 → 상세 / 수정 모달
- 프로젝트 연결 선택 (optional)
- 반복 일정 여부

**화면 흐름**:
```
캘린더 뷰
    │
    ├─ [날짜 클릭] → 모달: 제목 / 설명 / 시간 / 프로젝트 연결
    │
    └─ [일정 클릭] → 상세 모달 → [수정] / [삭제]
```

---

### 5. 이메일 목록 (`/emails`)

**목적**: 임포트된 이메일 목록 관리

**기능**:
- 이메일 목록 (발신자 / 제목 / 날짜)
- .eml 파일 가져오기 버튼 (파일 다이얼로그)
- 프로젝트 필터
- 검색 (제목 / 발신자)

**화면 흐름**:
```
이메일 목록
    │
    ├─ [.eml 가져오기] → 파일 선택 다이얼로그
    │       │
    │       └─ 파싱 완료 → 목록 갱신
    │
    └─ [이메일 행 클릭] → 이메일 상세 (/emails/:id)
```

---

### 6. 이메일 상세 (`/emails/:id`)

**목적**: 단일 이메일 내용 확인, AI 분석, 프로젝트 연결 관리

**레이아웃**:
```
┌──────────────────────────────────────────────────────┐
│ 제목 / 발신자 / 수신자 / 날짜                            │
├─────────────────────────────┬────────────────────────┤
│                             │   AI 분석 패널           │
│     이메일 본문               │                        │
│                             │  [요약 요청]             │
│                             │  [키워드 추출]            │
│                             │  [액션 아이템]            │
│                             │  [프로젝트 연결 추천]      │
│                             │                        │
│                             │  ─ 분석 결과 ─           │
│                             │  [결과 내용]             │
│                             │  [적용] [무시]           │
├─────────────────────────────┴────────────────────────┤
│ 연결된 프로젝트                                         │
│  ● 프로젝트명 (직접 연결)          [연결 해제]           │
│  ◎ 프로젝트명 (AI 추천, 대기 중)   [확정] [제거]         │
│  [+ 프로젝트 직접 연결]                                 │
├──────────────────────────────────────────────────────┤
│ 첨부파일 목록                                           │
└──────────────────────────────────────────────────────┘
```

**AI 내용 분석 흐름**:
```
[요약 요청] 클릭
    │
    ▼
로딩 표시 (Ollama 처리 중)
    │
    ▼
결과 표시 + [적용] [무시] 버튼
    │
    ├─ [적용] → is_applied=1 저장
    └─ [무시] → 결과 숨김 (DB에 is_applied=0 보존)
```

**AI 프로젝트 후보 선택 흐름**:
```
[프로젝트 연결 추천] 클릭
    │
    ▼
Ollama: 이메일 내용 기반 프로젝트 후보 추론 (로딩 중...)
    │
    ▼
후보 목록 표시
┌────────────────────────────────────────────────┐
│ AI 추천 프로젝트                                 │
│  ◎ [프로젝트 A]  신뢰도 87%    [확정]  [제거]   │
│  ◎ [프로젝트 B]  신뢰도 63%    [확정]  [제거]   │
│  ◎ [프로젝트 C]  신뢰도 41%    [확정]  [제거]   │
└────────────────────────────────────────────────┘
    │
    ├─ [확정] 클릭
    │       │
    │       ▼
    │   email_project_mappings: is_confirmed=0 → 1 업데이트
    │   화면: ◎ (대기) → ● (확정)으로 상태 전환
    │
    └─ [제거] 클릭
            │
            ▼
        email_project_mappings: 해당 행 삭제
        화면: 목록에서 제거
```

---

### 7. 설정 (`/settings`)

**목적**: 앱 동작 설정

**설정 항목**:
```
[ Ollama 설정 ]
  - 서버 URL (기본: http://localhost:11434)
  - 사용 모델 (드롭다운: 설치된 모델 목록 조회)
  - 연결 테스트 버튼

[ 이메일 ]
  - 첨부파일 저장 경로

[ 일반 ]
  - 언어 설정
```

## 화면 전환 흐름 전체도

```
대시보드
    ├─ 프로젝트 카드 → 프로젝트 상세
    ├─ 오늘 일정 → 일정 페이지 (해당 날짜 포커스)
    └─ 최근 메일 → 이메일 상세

사이드바 네비게이션
    ├─ 대시보드 (/)
    ├─ 프로젝트 (/projects)
    │       └─ 프로젝트 상세 (/projects/:id)
    ├─ 일정 (/schedule)
    ├─ 메일 (/emails)
    │       └─ 이메일 상세 (/emails/:id)
    └─ 설정 (/settings)
```

## 공통 UI 패턴

| 패턴 | 사용 시점 |
|------|---------|
| 모달 | 생성 / 수정 폼 (페이지 이동 없이 처리) |
| 확인 다이얼로그 | 삭제, AI 결과 적용 등 되돌릴 수 없는 작업 |
| 토스트 알림 | 저장 성공, 오류, AI 분석 완료 알림 |
| 로딩 스피너 | Ollama 응답 대기 중 (취소 버튼 포함) |
| 빈 상태 화면 | 데이터 없을 때 안내 메시지 |
